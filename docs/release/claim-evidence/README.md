# Claim Evidence Artifacts

This directory is reserved for separate evidence artifacts referenced by `docs/release/approved-claims.json`.

Rules:

- `externally_certified` claims require external audit/certification evidence.
- `internally_aligned` claims require internal control mapping evidence.
- `architecture_ready` claims require architecture/control design evidence.
- `demo_sample_metric` claims must be clearly demo/sample data, not production SLA evidence.
- The allowlist file must never reference itself as evidence.
