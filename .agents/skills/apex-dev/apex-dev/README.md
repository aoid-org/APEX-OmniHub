## Anti-Drift Protocol

The skill includes built-in drift detection:

```
□ Am I still solving the ORIGINAL task?
□ Have I introduced any provider lock-in?
□ Does this code have a test?
□ Is security considered?
□ Would this pass ARMAGEDDON Level 6?
```

**Loop Abort Triggers:**
- Same error 3x → Stop and re-read bug protocol
- Same code rewritten 3x → Extract to utility
- Task scope expanded 2x → Confirm with user
- File touched 5x without progress → Architectural issue
