# Design System Playbook

## Failures (❌)
- Hex colors everywhere → inconsistent roles.
- Duplicate components → drift.

## Correct Pattern (✅)
Role-based tokens → core components → docs → enforcement.

## Token roles
bg/surface/textPrimary/textSecondary/border/accent/danger/warn/success.
