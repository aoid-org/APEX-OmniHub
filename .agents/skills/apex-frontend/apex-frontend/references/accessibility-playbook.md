# Accessibility Playbook

## Failures (❌)
- Missing labels/roles.
- Color-only meaning.
- No focus order.

## Correct Pattern (✅)
Semantics → Focus → Contrast → Text scaling → Targets → Screen reader walk.

## Minimum checks
- Every control has a programmatic name.
- Logical reading order.
- Error messages explicit and recoverable.
