# Post-CI Remediation — 2026-06-17

Version: 1.0.0  
Date: 2026-06-17

## Scope

Restore post-CI and post-merge release signals for Python 3.10 compatibility, Sonar new-code coverage, Cloudflare Pages repository contract validation, and public claim hygiene for the OmniHub Proof app.

## Root Causes

1. Python modules and tests imported or referenced `datetime.UTC`, which is unavailable on Python 3.10. The remediation preserves timezone-aware UTC semantics with `timezone.utc`.
2. Sonar-reported new-code files lacked direct Vitest coverage for `apps/omnihub-proof/src/App.tsx`, `apps/omnihub-proof/src/main.tsx`, and one service-worker branch in `src/swInit.ts`.
3. The root release suite did not have a deterministic new-code LCOV guard for changed executable lines.
4. Cloudflare Pages reported an internal provider error after continuing without a Wrangler configuration file; the repository contract needed an explicit local guard and runbook.
5. `apps/omnihub-proof` is public-facing through `.github/workflows/deploy-omnihub-proof.yml`, so its proof copy was downgraded to evidence-review language and added to the claim-hygiene scan roots.

## Files Changed

- `orchestrator/**` and `omega/engine.py`: replaced Python 3.11-only UTC usage with Python 3.10-compatible aware UTC handling.
- `orchestrator/pyproject.toml`: aligned declared Python/tool targets to Python 3.10 compatibility.
- `apps/omnihub-proof/src/App.tsx`: reduced public proof claims to evidence-review language.
- `apps/omnihub-proof/src/main.tsx`: exported `mountOmniHubProof` and fail-closed when `#root` is missing while preserving production auto-mount behavior outside test mode.
- `tests/apps/omnihub-proof/App.spec.tsx`: added behavioral coverage for hero copy, CTAs, proof stats, cards, deployment evidence, tags, and contact link.
- `tests/apps/omnihub-proof/main.spec.tsx`: added behavioral coverage for explicit mount, missing-root failure, test-mode import guard, and production-mode auto-mount.
- `tests/pwa/swInit.spec.ts`: added branch coverage for no-window, unsupported service worker, successful registration, rejected registration without DEV warning, and rejected registration with DEV warning.
- `scripts/ci/check-new-code-coverage.mjs`: added an LCOV-based changed executable-line and branch coverage guard with a 90% threshold.
- `scripts/ci/verify-cloudflare-pages-contract.mjs`: added the Cloudflare Pages repository contract guard.
- `scripts/ci/check-coverage-integrity.mjs`: added OmniHub Proof source files to required LCOV entries.
- `scripts/ci/verify-claim-hygiene.mjs`: added `apps/omnihub-proof/src` to public-copy scan roots.
- `scripts/ci/verify-release.mjs` and `package.json`: wired new coverage and Cloudflare contract checks into release validation.
- `package.json`, `package-lock.json`, and `bun.lock`: pinned `@noble/hashes` at `1.8.0` so Bun installs expose the `sha2` export required by the current `ox`/Web3 import path.
- `tests/stress/spatial-frame-drops.test.ts` and `tests/omniconnect/validation.test.ts`: added warm-up calls before existing performance assertions to remove coverage/JIT cold-start noise without changing the thresholds.
- `public/sitemap.xml`: regenerated by the required build pre-step for 2026-06-17.
