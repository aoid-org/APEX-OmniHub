# Corrections

This directory holds meaningful corrections from the user.

## File Naming

`YYYY-MM-DD-<short-slug>.md`

## Template

```markdown
# Correction: <title>

Date: YYYY-MM-DD
Scope: local | project-wide | global
Permanent: yes | no

## Original Wrong Assumption
<what was wrong>

## Corrected State
<what is true>

## Affected Pages
- <list pages that need updating>

## Promoted To
- [ ] Local page fix
- [ ] Project-wide correction
- [ ] Global directive
- [ ] User preference rule
```

## Protocol

1. Write correction file here
2. Update affected pages immediately
3. If scope is global or permanent, promote to `_core_directives/` or `user-operating-model.md`
4. Mark promoted items as checked above
