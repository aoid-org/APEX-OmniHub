# Default Use Rule

Omni-Recall is active by default in all Claude Code sessions on this repo.

- Load `start-here.md` at session start when context continuity matters
- Apply `user-operating-model.md` preferences to all outputs
- Apply `do-not-do.md` as a hard constraint list
- Apply `quality-bar.md` before treating any Omni-Recall work as complete
- Write corrections to `wiki/corrections/` and promote stable ones immediately
- Supersede only when the user explicitly states a different preference for the session
